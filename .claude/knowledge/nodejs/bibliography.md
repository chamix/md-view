# Node.js / JavaScript Bibliography

Consumed as a **declared-per-task** knowledge module (ADR-006): the Lead
references this path in `full-stack-engineer`'s delegation prompt whenever
the task's stack is JavaScript/Node/React. Skip it entirely for tasks on
another stack (e.g. Python/Django) — that's the point of externalizing it.

Moved verbatim from `full-stack-engineer.md`'s former "Foundational
Technical Bibliography" section. The TDD/Kent Beck citation that used to
sit alongside these was dropped as redundant with the agent's own "TDD
Operational Flow" section, which already fully specifies the
Red-Green-Refactor process independent of any stack.

1. **Modern JavaScript & React Design Patterns:** Structure components,
   modules, and state synchronization per *Learning JavaScript Design
   Patterns* by Addy Osmani (2023).
2. **Advanced Runtime Mechanics:** Apply the engine dynamics from
   *Secrets of the JavaScript Ninja* by Resig, Bibeault, and Maras
   (2016): closures, execution contexts, prototype chains, event loops,
   microtask queues.
