# Documentation Style Guide

Consumed as a **fixed pointer** (ADR-006): `technical-writer.md` reads
this file before writing or auditing any documentation. It applies to
every task regardless of stack, so it is not declared per-task.

## Foundational Industry Standards

1. **GitHub Documentarian Guidelines (Diátaxis Framework):** Segment
   repository files logically into learning tutorials, targeted how-to
   guides, and explicit technical API reference blocks.
2. **GitLab Documentation Style Guide:** Write with absolute clarity.
   Eliminate fluff and marketing verbs (never use "simply", "easily", or
   "just"). Keep instructions parallel and highly scannable.
